# Lesson Engine

Кабинет учителя: конструктор урока с тремя ИИ-помощниками, доработка КМЖ, СОР/СОЧ, домашние задания и карточки.

## Запуск
Node.js 24. Установить зависимости: `npm install`. Скопировать `.env.example` в `.env.local` и указать API-ключ. Запуск: `npm start`. Открыть http://localhost:4173.

## Vercel
Импортировать этот репозиторий как проект. Root Directory: корень, Framework Preset: Other. Build Command и Output Directory не задавать: Vercel распознаёт `server.mjs` как Node.js server. Добавить серверную переменную `GROQ_API_KEY`, опционально `GROQ_MODEL=openai/gpt-oss-120b`, затем Deploy. Ключ не добавлять в исходники или публичные переменные.

Страницы и API обслуживаются одним сервером. PDF/DOCX обрабатываются библиотеками Node.js, без Python. Файлы до 3 МБ; PDF должен содержать текст. Документ отправляется ИИ только по кнопке пользователя.

Черновики и материалы хранятся в localStorage на устройстве пользователя. Это прототип без учётных записей; публичный API использует общую квоту владельца ключа. При публичном запуске включите защиту от злоупотреблений средствами Vercel.

GitHub Pages может размещать статический интерфейс из `dist`, но не серверные API. Для ИИ используется Vercel.
